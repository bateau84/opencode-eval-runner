# Evaluation report design

## Scope

This bundle records the human-readable report baseline for combined skill
evaluation. The design extends the accepted summary-first, same-report evidence
approach to multiple skill inputs and individually visible iterations. It does
not change evaluation semantics, machine-readable formats, branding, or report
scope beyond the approved baseline.
